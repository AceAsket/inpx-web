Первый отдельный Android-предрелиз INPX Web: сервер библиотеки на телефоне, планшете или ТВ-приставке, без Root и Termux.

## Скачать

- **ARM32** — `inpx-server-0.5.0-arm32-debug.apk`: для 32-битной Android на ARMv7 с NEON, включая старые приставки.
- **ARM64** — `inpx-server-0.5.0-arm64-debug.apk`: для 64-битной Android.
- Минимальная версия для обоих APK — **Android 9 (API 28)**, включая Android 10, 11 и 12+. Target SDK 36.

Архитектура APK должна соответствовать Android на устройстве. Если на 64-битном процессоре стоит 32-битная прошивка, нужен ARM32. Контрольные суммы находятся в соседних `.sha256`; состав и отпечаток сертификата — в `android-v0.5.0.json`.

## Возможности

- Два режима панели: сенсорный и ТВ с управлением стрелками/OK/«Назад», заметным фокусом и QR-кодом адреса каталога.
- Библиотеки через системный выбор папки (SD/USB) и SMB2/SMB3; чтение ZIP/7z по файловым дескрипторам.
- Диагностика источников, сохранение исправного INPX при отключении накопителя/NAS, повторные подключения.
- Фоновая foreground-служба со статичным уведомлением, настройками wake lock, автозапуска и поведения при отключении питания.
- В обеих сборках: fb2cng 1.9.0, MuPDF 1.27.0 и Kindling 0.45.6. FB2 → EPUB, EPUB3, KEPUB, KFX, AZW8, PDF, MOBI.
- Кнопка сообщества [INPX Web в Telegram](https://t.me/inpxweb), копирование ссылки и QR-код.

## Проверено

ARM64 установлен на Lenovo TB321FU с Android 16: 49 проверок интерфейса, шесть проверок фоновой работы, все семь нативных конвертаций. По Wi-Fi проверены каталог, поиск, две книги ZIP/7z из сохранённой SAF-папки и 14 конвертированных скачиваний. Обновление сохранило выбранный источник.

Для обеих архитектур прошли сборка и Android Lint (0 ошибок), проверка подписи APK, минимального API 28, состава и архитектуры всех семи ELF-бинарников. **ARM32 и Android 9–11 ещё не запускались на физическом устройстве**: подключённый планшет поддерживает только ARM64. Большие библиотеки на маломощных приставках, реальные USB/SD, длительная работа во сне и особенности ТВ-прошивок требуют аппаратной проверки.

Это прототип с **debug-подписью**, для ручной установки и проверки. Backend внутри APK — проверенный снимок **1.8.1-rc.4** (`fd1df1ab`), Node.js 24.22.1. Исходники Android, инструкции сборки и подробные результаты: [ветка android](https://github.com/AceAsket/inpx-web/tree/android/android). Лицензии включены в APK; MuPDF распространяется под AGPL.
