INPX Server 0.7.3 для Android 9+ на ARM32 и ARM64. Встроенный сервер обновлён до 1.8.3-rc.2.

- Запуск можно отменить с главного экрана и из журнала. Если сервер завис и не завершился штатно, Android-приложение остановит его отдельный процесс примерно через 18 секунд. После этого можно запустить сервер снова.
- Экран показывает текущий этап запуска, процент для измеряемых этапов, число обработанных записей и время последнего изменения. Последний этап остаётся доступен после сна или при потере ответа сервера.
- Журнал обновляется, пока открыт. Если прокрутить его вверх, можно продолжать читать предыдущие строки.

Остановите сервер и установите APK поверх прежней версии. Подпись совместима с 0.7.2.
