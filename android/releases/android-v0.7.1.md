Android 0.7.1 — сервер 1.8.2-rc.24, ARM32 / ARM64, Android 9+

- Сервер обновлён до **1.8.2-rc.24**. Включены исправления пагинации веб-читалки, имён файлов для Kindle и сохранения идентификаторов книг при переносе библиотеки из RC21–RC24.
- При импорте больших INPX промежуточные поисковые данные записываются во внутреннее хранилище. Новый индекс заменяет старый после завершения сборки. На панели видно число обработанных записей.
- На главном экране видно фактическое потребление ОЗУ серверным процессом. **Настройки → Память** позволяют выбрать лимит кучи Node.js. После подтверждённого сбоя из-за лимита приложение предлагает повысить его и запустить сервер снова.
- Иконка взята из INPX Reader и используется в приложении и лаунчере Android TV.
- Включены 7-Zip 26.03, fb2cng 1.9.0, MuPDF 1.27.0 и Kindling 0.45.6 на обеих архитектурах: EPUB, EPUB3, KEPUB, KFX, AZW8, PDF и MOBI.

**Установка:** APK можно установить поверх 0.7.0 с сохранением источников и настроек. Для 32-битной Android нужен ARM32 (ARMv7 с NEON), для 64-битной — ARM64. Версия `0.7.1-prototype`, versionCode `9`, прежний сертификат подписи.

Во время первой индексации требуется дополнительное свободное место во внутреннем хранилище. При обновлении уже готового каталога сервер сохраняет действующий индекс до завершения сборки нового. Если памяти не хватило при открытии уже собранного индекса, при запуске с новым лимитом сервер открывает готовый индекс.
