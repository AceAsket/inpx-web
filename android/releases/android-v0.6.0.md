Android 0.6.0 — ARM32 / ARM64, Android 9+

- Backend обновлён с 1.8.1-rc.4 до **1.8.2-rc.1**: включены исправления поиска, памяти, читалки, профилей, форматов и OPDS из актуального сервера.
- Включены улучшения панели 0.6: Presenter/Repository, подсказки первого подключения, отдельные состояния запуска и остановки, сохранение фокуса пульта, диагностика неприменённых настроек. Сохранены форматы Vault, источников и настроек службы.
- Упаковщик включает новые серверные зависимости. Изолированный runtime проверяется отдельно от node_modules машины сборки, включая поиск по оценкам и общие подборки OPDS.
- Добавлена автоматическая сборка ARM32/ARM64 в GitHub Actions, серверные проверки, JVM-тесты, Android Lint, контроль ABI, версии runtime и сертификата подписи. Общие подборки OPDS остаются необязательной настройкой запуска сервера.

**Установка:** выберите APK по разрядности Android, установите поверх прежнего приложения. Для 32-битной Android нужен ARM32, даже на 64-битном процессоре. Нужен Android 9+; ARM32 требует ARMv7 с NEON. VersionName `0.6.0-prototype`, versionCode `7`; подпись прежняя, данные приложения сохраняются. Рядом с APK доступны SHA256 и JSON с составом сборки.

**Проверки:** автоматические проверки не означают тестирование этой сборки на физическом устройстве. При выпуске нового backend устройство по ADB не было подключено. Предыдущие сборки ARM64 проверялись на Android 16; ARM32 и конкретные SD/USB/SMB-сценарии нужно проверять на своём оборудовании.

Это проверочный предрелиз с debug-подписью. Нативные инструменты: 7-Zip 26.03, fb2cng 1.9.0, MuPDF 1.27.0 и Kindling 0.45.6; лицензии включены в APK. Версии для ПК и Docker публикуются отдельно.
