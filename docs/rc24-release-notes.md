# 1.8.2-rc.24

При горизонтальном листании читалка теперь учитывает боковые поля при расчёте ширины страницы. Переносы в расчёте совпадают с переносами на экране, поэтому последние строки помещаются в отрисованную страницу. Включены исправления RC23 для переноса INPX-библиотеки и пересчёта страниц при уменьшении окна. [Изменения RC23](./rc23-release-notes.md)

## Проверки

В Firefox проверены 24 страницы вокруг фрагментов из глав 22 и 24 книги «Маг, запирающий страны». Использовались тема e-ink, Serif 18 px, интервал 1,40, ширина по экрану, нулевые вертикальные поля и горизонтальное листание. Все строки видны, текст при перелистывании идёт подряд. В Chromium прошёл тест полноэкранного режима, нижней панели и совпадения расчётной ширины с видимой при горизонтальном листании.
