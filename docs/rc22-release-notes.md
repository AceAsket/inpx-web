# 1.8.2-rc.22

- Читалка определяет границы страниц по высоте отрисованного текста. Продолжение абзаца сохраняется при перелистывании, а скрытие верхней панели освобождает место под текст.
- Во время фонового пересчёта нижняя панель продолжает показывать страницу, главу, прогресс и часы. При первом открытии книги виден индикатор разбивки.
- Включены изменения RC21 для ASCII-имён скачивания в `/ebook` на Kindle. [Изменения RC21](./rc21-release-notes.md)

## Проверка читалки

На Windows в Яндекс Браузере 26.8.5.811 и Chromium проверены перелистывание, скрытие панели щелчком по центру и полноэкранный режим браузера. В Яндекс Браузере разбивка оставалась завершённой 25 секунд. Проверочная FB2 с иллюстрациями прошла 168 страниц без обрезанных строк и с исходным порядком текста.

На стенде откройте главу 11 книги «Маг, запирающий страны» около 42% прогресса и перелистните границу, на которой раньше пропадали строки. После обновления номера страниц могут измениться. Затем скройте панель щелчком по центру и проверьте полноэкранный режим.
