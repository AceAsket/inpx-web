# 1.8.2-rc.25

Читалка сохраняет место чтения при скрытии панели щелчком по центру и при переключении полноэкранного режима кнопкой. После выхода исходная разбивка восстанавливается с тем же текстом. При перелистывании читалка запоминает новую позицию. [Изменения RC24](./rc24-release-notes.md)

- Docker `aceasket/inpx-web-7z:1.8.2-rc.25`.
- Silero `aceasket/inpx-web-7z:1.8.2-rc.25-silero`.
- [Архивы Linux, Windows и macOS и установщик Windows](https://github.com/AceAsket/inpx-web/releases/tag/v1.8.2-rc.25).
