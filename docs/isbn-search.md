# Поиск по ISBN

В дополнительных фильтрах каталога есть отдельное поле «ISBN». Поддерживаются ISBN-10 и ISBN-13, запись с пробелами и дефисами, префикс `ISBN:`. Контрольная цифра проверяется. Эквивалентные ISBN-10 и ISBN-13 с префиксом 978 находят одну подборку; другой ISBN другого издания не считается совпадением.

Примеры одного номера: `0-306-40615-2`, `0306406152`, `9780306406157`. Ввод номера в «Название» по-прежнему означает поиск по названию. ISBN можно совмещать с автором, языком, источником и другими фильтрами, а также сохранять в умной полке.

## Подготовка индекса

Войдите под администратором, откройте **Задачи → Индекс ISBN → Подготовить ISBN**. Номера берутся из поля ISBN записи каталога, если оно есть, либо из метаданных FB2/EPUB. Для EPUB учитываются все корректные ISBN в идентификаторах пакета. Если в книге ISBN не указан или записан с неверной контрольной цифрой, по нему она не находится.

Первое чтение файлов большой библиотеки может занять много времени. Оно запускается только вручную, работает в общем фоновом бюджете, не меняет оригиналы и не запускает конвертацию. Обычный поиск остаётся доступен. В окне задач видны прогресс, число книг с ISBN, пропуски и ошибки чтения.

Подготовку можно отменить и продолжить. Индекс хранится в `isbn-index.json` внутри постоянного каталога данных; контрольная точка сохраняется каждые 5000 записей, при отмене и завершении. После аварийного завершения повторно обрабатывается незавершённый участок. До завершения индексирования запрос ISBN сообщает о неподготовленном индексе вместо выдачи неполного результата.

После изменения поисковой базы требуется новая подготовка. Если исходный файл изменён без обновления каталога, используйте **Перестроить ISBN полностью**. Перестройка также заменяет старый кэш результатов ISBN. Ошибки отдельных файлов не прерывают обработку; такие книги могут отсутствовать в результатах, поэтому проверяйте счётчик «не прочитано».

Максимальный размер читаемой книги задаётся при запуске через `INPX_ISBN_MAX_BOOK_MB` (по умолчанию 64 МБ) либо `INPX_ISBN_MAX_BOOK_BYTES`. Более крупные файлы отмечаются как непрочитанные, а не как книги без ISBN. Для ZIP/7z применяются ограничения размера и общего бюджета внешних процессов; временные EPUB удаляются после чтения.

Подготовка доступна только на сервере с локальными исходными файлами. Для режима удалённой библиотеки эта версия не синхронизирует индекс ISBN: такой поиск недоступен.
