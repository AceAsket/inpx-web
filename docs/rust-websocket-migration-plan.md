## Переход с сервера Node.js на автономный Rust

Приоритет — совместимость серверных функций и данных на локальной установке. Сборка Vue и упаковка релиза используют Node.js. Установленный Rust-сервер запускается самостоятельно.

1. **Конвертация книг.** Сначала подключить fb2cng для EPUB, EPUB3, KEPUB, KFX и AZW8. Сохранить настройки форматов и общий кэш для веб-скачивания, OPDS, Telegram и почты. Затем добавить MOBI через Kindling и PDF через MuPDF, проверить настройки Calibre и пользовательский YAML. Проверить готовые файлы, параллельные запросы, изменение параметров конвертации, ошибки и возврат к оригиналу для неподдерживаемого предпочтения.
2. **Удалённая библиотека.** Добавить клиент `remoteLib`. Проверить загрузку INPX без повторного скачивания при совпадении хэша, загрузку книг, поток метаданных и рейтингов, ошибки сети и переподключение. Проверить пары Rust–Rust и Rust–RC15. Поставщик INPX и метаданных уже реализован.
3. **Интерфейс `/ebook`.** Перенести HTML-страницы и формы для устройств без JavaScript. Проверить серверный поиск, полки, вход с 2FA, параметры скачивания и восстановление позиции чтения. Использовать текущие Rust-хранилища профилей и каталога.
4. **Фильтры INPX.** Собрать примеры используемого поля `filter`, определить декларативное представление и миграцию правил. Проверить одинаковый состав каталога с RC15 и применение фильтров при переиндексации. Поддержку произвольного JavaScript оценить по этим примерам.
5. **Сборка и обновление.** Сверить HTTP-маршруты и настройки релиза, прогнать оба режима на одной копии установки, проверить переиндексацию, OPDS, отправку и бэкап. Измерить время первого запуска и поиска на той же копии. После прохождения проверок переключить Docker-сборку по умолчанию на Rust.

Для Unraid проверить используемые функции на копии `appdata` с библиотекой, подключённой для чтения. После проверки можно обновить рабочий контейнер, сохранив прежний образ и исходную копию данных для отката.

### Конвертация книг

Docker-цель `runtime-rust` включает fb2cng для EPUB, EPUB3, KEPUB, KFX и AZW8, Kindling для MOBI7/KF8 и MuPDF для PDF. PDF из FB2 и EPUB также можно получить через Calibre в варианте `runtime-calibre` с Rust-сервером. Скачивание, OPDS, Telegram и SMTP используют общий кэш и очередь.

Шаблон заголовка применяется на этапе fb2cng, включая подготовку EPUB для MOBI из FB2. Его результат и содержимое YAML входят в ключ кэша, а относительные пути к CSS и шрифтам сохраняются. Изменение доступных форматов применяется при перезапуске.

На тестовой библиотеке проверены оба исходных формата, скачивание, OPDS, отправка в тестовые Telegram и SMTP, общий кэш и возврат к оригиналу при недоступном предпочтительном формате. Тест очереди проверяет поиск во время конвертации, заполнение очереди и очистку временных файлов при таймауте. Для Calibre проверяются метаданные PDF, чтобы подтвердить выбор настроенного конвертера. Прогон запускается через `scripts/rust-conversion-tests.js` с тегами основного образа и варианта с Calibre.

### Клиент удалённой библиотеки

Rust использует `remoteLib` для загрузки INPX и книг и для чтения отзывов,
биографий и оценок. Клиент сохраняет `remote.inpx` атомарно, сравнивает
SHA-256 при обновлении и сохраняет доступ к текущему каталогу при обрыве связи.
На стороне клиента число голосов сопоставляется с локальными UID после
получения всех страниц одной ревизии. Тест `scripts/rust-remote-tests.js`
принимает образы Rust и тега `v1.8.3-rc.15`.

В обоих контейнерных прогонах подтверждены ответ без архива при совпадении
SHA-256, скачивание FB2 и EPUB и повторное подключение после обрыва.
Проверены 12 отзывов, индекс голосов из 1002 записей и обновление INPX,
отзывов, биографии и оценок после восстановления связи. Переиндексация
читает идентификаторы через открытый Redb и переключает готовый индекс
после завершения построения.

### Интерфейс для электронных книг

Rust обслуживает `/ebook` серверными HTML-страницами и формами. Поиск и
полки используют текущий каталог, а вход и 2FA используют общие с веб-версией
профили и сеансы. Формат скачивания, выбранный в профиле, сохраняется в
профиле. У гостя выбор передаётся в ссылке с расширением книги.

Перелистывание записывает позицию в общий журнал чтения. Позиция
восстанавливается по сохранённому фрагменту текста и проценту чтения.
Браузерный прогон `scripts/rust-ebook-browser-test.js` принимает тег
Rust-образа и запускает Chromium с отключённым JavaScript.

Проверены совместный поиск по названию и автору, личная и умная полки,
вход с TOTP и резервным кодом, скачивание EPUB, MOBI и исходного FB2.
При отправке устаревшей формы перелистывания действует более новая позиция из профиля.
После повторного входа открывается сохранённый фрагмент текста.

### Фильтры INPX

Rust загружает старые правила `filter.json` при построении нового индекса.
Поддерживаемые выражения в `filter` используют поля записи, литералы,
сравнения, логические операции и перечисленные в README строковые методы.
Списки авторов и переименование коллекции используют прежний формат.
Ошибка в правиле оставляет доступным опубликованный индекс.

`scripts/rust-inpx-filter-tests.js` сравнивает записи из Redb и JembaDB
на одной копии INPX из 819 709 записей. Документированное правило RC15 со
списком авторов оставило 367 книг в обоих контейнерах. После изменения
правила и переиндексации без перезапуска осталось по 253 книги. Состав
совпал в обоих прогонах, а оставшиеся книги сохранили внутренние ID в Rust.
При ошибке в следующем правиле Rust продолжил использовать готовый индекс.
