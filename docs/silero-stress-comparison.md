# Локальная проверка silero-stress

Проверка 2026-10-08: встроенный акцентор модели `v5_5_ru` для Xenia и отдельный `silero-stress==1.5`. Сценарий воспроизводится командой `python tts/silero/compare_stress.py --output comparison.json`; модель TTS должна быть в `SILERO_MODEL_DIR`. Библиотека silero-stress и зависимости сервиса должны быть установлены.

В сценарии 20 коротких фраз: 18 проверок конкретного омографа и две проверки ручных `+`/«ё». Ожидаемые варианты заданы вручную. Проверяется выбранное слово, а не все слова предложения. Это небольшой диагностический набор, не репрезентативная оценка качества на книгах.

| Проверка | Встроенный TTS | silero-stress 1.5 |
|---|---|---|
| Правильные выбранные слова | 16/20 | 19/20 |
| Сохранение ручного ударения и «ё» | 2/2 | 2/2 |
| Время обработки 20 фраз после прогрева | 0,102 сек | 0,087 сек |

Загрузка внешнего акцентора заняла 1,931 секунды. Замеры сделаны на локальном Windows-хосте, Python 3.13, Torch 2.13.0 CPU, четыре потока. Небольшие различия времени не доказывают преимущество в производительности на другом сервере; образ использует Torch 2.8.0 CPU, оба режима проверяются при сборке образа.

| Пример | Ожидаемый вариант | Встроенный | Внешний |
|---|---|---|---|
| Эта книга стоит дорого. | ст+оит | сто+ит | ст+оит |
| Он уже пришёл. | уж+е | +уже | уж+е |
| Атлас мира лежит на столе. | +атлас | атл+ас | +атлас |
| Маленькие гвоздики лежат в коробке. | гв+оздики | гвозд+ики | гв+оздики |
| На горе стоит старый замок. | з+амок | з+амок | зам+ок |

Новый акцентор улучшил четыре выбранных случая и ухудшил один. Он включён по умолчанию по решению пользователя; `SILERO_STRESS_ENABLED=false` возвращает встроенный акцентор. Для последнего примера ручное `замок = з+амок` исправляет конкретный вариант, но такая замена действует на все употребления слова в книге.

Оба режима отдельно прошли реальный синтез через сервис: короткая проба, паузы, низкая высота голоса, словарь с явными ударениями, выдача MP3. Дополнительные шесть секунд пауз подтверждены размером и длительностью MP3. Проверены разделение кэша и позиции между акценторами, ленивый запуск, восстановление потоков Torch и отключение всех встроенных флагов ударений при внешней обработке.
