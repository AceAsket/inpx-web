# 1.8.2-rc.23

- При пересборке после переноса INPX-библиотеки индекс различает одинаковые строки из разных архивов и сохраняет идентификаторы книг, к которым привязаны прогресс и закладки.
- При ошибке создания индекса таймер перестаёт отправлять обновления. Когда сервер загружает прежнюю базу, индикатор подсчёта статистики закрывается.
- При уменьшении области чтения индикатор занимает место страницы до завершения разбивки. Читалка удерживает позицию, а нижняя панель показывает прежний номер страницы и прогресс до появления новой раскладки.

## Проверки

На временной библиотеке с папкой `_Lib.rus.ec - Официальная` проверены перенос, сохранение UID и скачивание FB2 из двух архивов по новому пути. При принудительной ошибке пересборки сервер вернулся к прежней базе и сохранил доступ к поиску.

На «Маге, запирающем страны» в Firefox проверено уменьшение окна во время чтения главы 24. Нажатие PageDown в этот момент сохранило место. В Chromium и Яндекс Браузере прошли проверка нижней панели, полноэкранного режима и перелистывание 51 страницы тестовой FB2.
