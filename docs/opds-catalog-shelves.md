# Общие подборки OPDS

Доступны с **1.8.2-rc.1**. Администратор сервера может добавить разделы в корень
OPDS, например «Новинки фантастики» или «Книги на английском». Подборки общие для
всего каталога и доступны без выбора профиля. Обычные проверки входа, Basic Auth
и SSO продолжают действовать: общая подборка не открывает закрытый сервер.

Личные умные полки настраиваются в веб-интерфейсе и остаются привязаны к профилю.
Общие подборки используют тот же поиск и фильтры, но не публикуют личные списки,
отметки чтения и прогресс. Настройки общих подборок задаются только при запуске
сервера и через файл; в панели администратора их нет.

## Подключение на Unraid

Создайте каталог `/mnt/user/appdata/inpx-web-opds` и сохраните в нём файл
`feeds.json`:

Готовый файл также есть в [examples/opds-feeds.json](../examples/opds-feeds.json).

```json
{
  "version": 1,
  "shelves": [
    {
      "id": "new-fantasy",
      "name": "Новинки фантастики за месяц",
      "grouping": "authors",
      "filters": {
        "genre": "sf_fantasy",
        "lang": "ru",
        "date": "month"
      }
    },
    {
      "id": "rated-scifi",
      "name": "Фантастика с 20 и более оценками",
      "grouping": "series",
      "filters": {
        "genre": "sf",
        "ratingCount": "20.."
      }
    },
    {
      "id": "english",
      "name": "Книги на английском",
      "grouping": "books",
      "filters": {
        "lang": "en",
        "ext": "fb2|epub",
        "hideCopies": true
      }
    }
  ]
}
```

Сохраните свои обычные параметры запуска и добавьте **перед именем образа**:

```sh
-e INPX_OPDS_FEEDS_FILE=/config/opds/feeds.json \
-v /mnt/user/appdata/inpx-web-opds:/config/opds:ro \
aceasket/inpx-web-7z:1.8.2-rc.1
```

Подключайте каталог целиком: тогда замена JSON-файла редактором будет видна
контейнеру. После первого добавления переменной контейнер нужно пересоздать.
Дальнейшие изменения JSON подхватываются при новом обращении к OPDS, без
перезапуска. Рекомендуется записывать изменения во временный файл в этом же
каталоге и затем переименовывать его в `feeds.json`, чтобы запрос не попал на
частично записанный JSON.

В Compose добавьте в `environment`:

```yaml
INPX_OPDS_FEEDS_FILE: /config/opds/feeds.json
```

И в `volumes` основного контейнера:

```yaml
- /mnt/user/appdata/inpx-web-opds:/config/opds:ro
```

Путь задаётся внутри контейнера. Для standalone-сервера задайте ту же переменную
окружения; относительный путь считается от каталога данных. Если переменная не
задана, общие подборки выключены. Файл хранится отдельно от профилей и не входит
в экспорт профиля: сохраняйте его вместе с конфигурацией развёртывания.

## Формат и поведение

- `version`: сейчас только `1`. В `shelves` можно задать до 64 подборок;
  максимальный размер файла — 256 КиБ.
- `id`: уникальный идентификатор длиной до 64 символов: латинские буквы, цифры,
  дефис и подчёркивание; первый символ — буква или цифра. Сохраняйте его при
  переименовании подборки, чтобы ранее сохранённые ссылки продолжали работать.
- `name`: видимое название, до 100 символов.
- `active: false`: скрыть подборку и закрыть её ссылку. По умолчанию включена.
- `grouping`: `books` (по умолчанию), `authors` или `series`. При группировке по
  авторам учитываются отдельные соавторы; в серии книги идут по номеру.
- `filters`: хотя бы один фильтр. Поддерживаются `author`, `title`, `series`,
  `genre`, `lang`, `ext`, `date`, `librate`, `ratingCount`, `keywords`, `sourceId`,
  `isbn` со строковыми значениями, а также логический `hideCopies`.

Условия поиска работают как в умных полках. `date` поддерживает `today`,
`3days`, `week`, `2weeks`, `month`, `2months`, `3months`; границы пересчитываются
при обращении, а не фиксируются при старте. Для ISBN сначала подготовьте индекс
в окне «Задачи»; [инструкция ISBN](isbn-search.md). Для фильтра числа оценок также
нужен готовый индекс; первый запрос может ожидать его подготовки. Источник
`sourceId` должен соответствовать идентификатору настроенной библиотеки.
Жанры выбираются по точным кодам из вашей коллекции; родительский код не
подразумевает автоматическое включение всех дочерних жанров.

Удалённые книги исключаются. Фильтры личного состояния (`unreadOnly`, профиль,
прочитано/скрыто) в общих подборках запрещены. Параметры URL не могут менять
условия из файла. В URL задаются только подборка `id`, страница `page`, выбранная
группа `group` и обычная область профиля `user`.

Страница содержит до 50 книг или групп. Повторные запросы разделяют расчёт;
краткоживущий кэш ограничен двумя выборками, одновременно рассчитываются не более
двух разных выборок. Полные записи книг загружаются только для текущей страницы.
Изменения индекса, фильтров и относительной даты не используют прежнюю выборку.
При обновлении самой базы нужно заново открыть группу: её внутренний ID может
измениться. Ссылка на подборку с постоянным `id` сохранится.

При ошибке JSON, превышении лимита или недоступном файле обычные разделы OPDS
остаются доступны. В корне появится «Общие подборки временно недоступны», а при
переходе сервер вернёт HTTP 503. Причина записывается в серверный журнал.
После исправления файла работа восстановится на следующем запросе. Удалённая
или отключённая подборка возвращает HTTP 404, в том числе по старой ссылке.
