# Озвучка книг через Silero

Экспериментальная серверная озвучка русских FB2, **выключенная по умолчанию**. Включается только при запуске контейнера переменной `INPX_TTS_ENABLED=true`; настройки администратора эту опцию не меняют. Silero работает в отдельном CPU-контейнере; основное приложение не требует Python или PyTorch. Текст книги передаётся только вашему сервису Silero.

## Docker Compose

Используйте текущие пути библиотеки и данных в `docker-compose.yml`, затем:

```sh
export INPX_TTS_ENABLED=true
docker compose -f docker-compose.yml -f docker-compose.silero.yml --profile tts pull
docker compose -f docker-compose.yml -f docker-compose.silero.yml --profile tts up -d --no-build
```

Для стенда RC6 опубликованы образы `aceasket/inpx-web-7z:1.7.9-rc.6` и `aceasket/inpx-web-7z:1.7.9-rc.6-silero` для Linux x64. Возьмите `docker-compose.silero.yml` из тега `v1.7.9-rc.6`; основной Compose-файл с вашими путями и портами сохраняется. Для сборки из исходников замените `--no-build` на `--build` и пропустите `pull`.

При первой озвучке сервис скачает официальную модель `v5_5_ru` в постоянный том `silero-models`. Для первого запуска нужен доступ к `models.silero.ai`; последующие запуски используют локальную модель. Контейнер по умолчанию использует до 4 CPU и 4 ГБ RAM. `/health` проверяет доступность HTTP-сервиса; модель загружается при первом запросе синтеза.

Сервис Silero включён в необязательный Compose-профиль `tts`. Без `--profile tts` он не запускается; основной контейнер работает без него. Сам адрес `INPX_TTS_URL` не включает озвучку. Чтобы выключить озвучку, задайте `INPX_TTS_ENABLED=false` и пересоздайте основной контейнер; ненужный сервис можно остановить командой `docker compose -f docker-compose.yml -f docker-compose.silero.yml stop silero`.

Для существующего контейнера INPX Web на Unraid загрузите сервис отдельно:

```sh
docker pull aceasket/inpx-web-7z:1.7.9-rc.6-silero
```

Подключите оба контейнера к одной пользовательской Docker-сети, запустите Silero с именем `silero`, портом `8000` внутри сети и постоянным томом `/models`. В **новой сборке** INPX Web задайте `INPX_TTS_ENABLED=true` и `INPX_TTS_URL=http://silero:8000`. При использовании разных хостов укажите адрес и доступный порт вашего Silero. После изменения переменных пересоздайте контейнер INPX Web.

## Docker run на Unraid

Для нового сервиса Silero создайте сеть и запустите контейнер. Порт сервиса остаётся внутри сети; модель хранится в `/mnt/user/appdata/inpx-silero`.

```sh
docker pull aceasket/inpx-web-7z:1.7.9-rc.6-silero &&
(docker network inspect inpx-tts >/dev/null 2>&1 || docker network create inpx-tts) &&
docker run -d --name silero --restart unless-stopped --network inpx-tts \
  --cpus=4 --memory=4g \
  -e SILERO_MODEL=v5_5_ru -e SILERO_THREADS=4 \
  -v /mnt/user/appdata/inpx-silero:/models \
  aceasket/inpx-web-7z:1.7.9-rc.6-silero
```

Затем замените существующий `inpx-web`, сохранив переменные запуска, включая токен Audiobookshelf. Команда ниже использует пути стенда `/mnt/user/appdata/inpx-web` и `/mnt/user/Torrents`.

```sh
inpx_env_file=$(mktemp) &&
docker pull aceasket/inpx-web-7z:1.7.9-rc.6 &&
docker inspect --format '{{range .Config.Env}}{{println .}}{{end}}' inpx-web > "$inpx_env_file" &&
docker stop inpx-web && docker rm inpx-web &&
docker run -d --name inpx-web --restart unless-stopped --network inpx-tts \
  -p 12380:12380 --env-file "$inpx_env_file" \
  -e INPX_ABS_ENABLED=true \
  -e INPX_TTS_ENABLED=true -e INPX_TTS_URL=http://silero:8000 \
  -e INPX_TTS_MODEL=v5_5_ru \
  -v /mnt/user/appdata/inpx-web:/usr/local/bin/.inpx-web \
  -v /mnt/user/Torrents:/library:ro \
  aceasket/inpx-web-7z:1.7.9-rc.6 &&
rm -f "$inpx_env_file"
```

Первый блок нужен для первоначального запуска Silero. Если сервис уже работает в другой сети, подключите его к `inpx-tts` через `docker network connect inpx-tts silero`; сеть при необходимости создаётся командой из первого блока. После этого выполняйте только второй блок. Чтобы оставить озвучку выключенной, задайте `INPX_TTS_ENABLED=false` при замене основного контейнера.

### Обновление существующего Silero на стенде

Для перехода с RC5 обновите также работающий `silero`, сохранив его переменные и модель. Сеть и пути — из приведённого выше запуска стенда. После этой команды выполните блок замены `inpx-web` выше.

```sh
silero_env_file=$(mktemp) &&
docker pull aceasket/inpx-web-7z:1.7.9-rc.6-silero &&
docker inspect --format '{{range .Config.Env}}{{println .}}{{end}}' silero > "$silero_env_file" &&
docker stop silero && docker rm silero &&
docker run -d --name silero --restart unless-stopped --network inpx-tts \
  --cpus=4 --memory=4g --env-file "$silero_env_file" \
  -e SILERO_MODEL=v5_5_ru -e SILERO_THREADS=4 \
  -v /mnt/user/appdata/inpx-silero:/models \
  aceasket/inpx-web-7z:1.7.9-rc.6-silero &&
rm -f "$silero_env_file"
```

## Использование

Войдите в профиль, откройте FB2 в читалке и нажмите значок наушников. Доступны пять русских голосов: Xenia, Kseniya, Бая, Айдар, Евгений. Кнопка «Послушать голос · короткая проба» озвучивает один и тот же небольшой русский текст выбранным голосом; готовая проба кэшируется независимо от книги. Это позволяет сравнить дикторов перед началом подготовки.

Выберите режим:

- **Слушать сразу** — по умолчанию. Подготавливаются небольшие фрагменты до 700 символов, затем следующий фрагмент готовится заранее. Для начала не требуется создавать аудио всей книги. Уже подготовленные фрагменты сохраняются в кэше для продолжения.
- **По главам** — выберите главу и начните прослушивание после её подготовки. Очень длинные главы разбиваются на части до 6000 символов; следующий раздел подготавливается заранее. Вложенные главы и промежуточный текст сохраняют порядок без повторов.
- **Вся книга в MP3** — единая запись, доступная после завершения подготовки. На CPU большой роман может готовиться долго.

Перед запуском показывается примерное время подготовки и ожидания в очереди. До первого синтеза это предварительная оценка; после пробы или главы сервис уточняет её по фактической скорости этого сервера. Загрузка модели при холодном запуске учитывается отдельно. Во время синтеза отображаются процент обработанного текста и примерное оставшееся время. Для новых функций нужно обновить **оба контейнера**, INPX Web и Silero; старый сервис продолжает синтезировать, но не сообщает прогресс и оценку времени.

Когда появится плеер, нажмите ▶. Скорость 0,75×–2× регулируется **плеером**, без изменения параметров синтеза и повторного создания MP3. Смена голоса создаёт отдельную запись. Заголовки и основной текст читаются; описание, изображения, маркеры сносок и тело `notes` пропускаются.

Плеер использует MP3, HTTP Range для перемотки и Media Session для кнопок на экране блокировки. В режимах «Слушать сразу» и «По главам» переключение между записями выполняется в браузере; следующая запись предварительно загружается. При недостаточной скорости CPU или сети возможна пауза между фрагментами. Приостановка фоновой вкладки конкретным телефоном тоже может прервать переход: проверьте работу с выключенным экраном в своём браузере. Режим «Вся книга» после старта не требует переключения фрагментов. Сервер продолжает начатую подготовку и после закрытия страницы, а повторное открытие использует задание или кэш.

Место (включая номер главы/фрагмента) и скорость сохраняются в этом браузере отдельно для профиля, книги, голоса и режима. Синхронизация позиции аудио между устройствами и привязка к текущему абзацу читалки пока отсутствуют. Закрытие плеера, смена книги, выход или смена профиля останавливают звук; сворачивание плеера сохраняет воспроизведение. На мобильном экране свёрнутый плеер располагается под шапкой и не закрывает нижние кнопки.

## Настройка

Разделители вроде `***` пропускаются, целые числа преобразуются в русские слова. Самостоятельные абзацы без русских букв и чисел пропускаются: эта модель предназначена для русского текста. Грамматическая обработка дат, дробей и порядковых числительных пока отсутствует.

| Переменная INPX Web | По умолчанию | Назначение |
| --- | --- | --- |
| `INPX_TTS_ENABLED` | `false` | Явно включает озвучку только при значении `true`; одного адреса недостаточно |
| `INPX_TTS_URL` | пусто | Адрес Silero; без него кнопка озвучки скрыта |
| `INPX_TTS_MODEL` | `v5_5_ru` | Должна совпадать с `SILERO_MODEL` сервиса |
| `INPX_TTS_CACHE_SIZE_MB` | `4096` | Лимит кэша MP3, минимум 64 МБ |
| `INPX_TTS_TIMEOUT_MS` | `3600000` | Максимальное ожидание синтеза одной книги, в миллисекундах |
| `INPX_TTS_API_KEY` | пусто | При необходимости Bearer-ключ, совпадающий с `SILERO_API_KEY` сервиса |

Переменные сервиса: `SILERO_MODEL=v5_5_ru`, `SILERO_MODEL_DIR=/models`, `SILERO_THREADS=4`, необязательный `SILERO_API_KEY`. `SILERO_ESTIMATED_CHARS_PER_SECOND=15` задаёт начальную скорость для предварительной оценки; после первого синтеза используется измеренная скорость. Не публикуйте незащищённый сервис в интернет; пример Compose оставляет его доступным только внутри сети.

MP3 хранятся в `<dataDir>/speech`. Очередь ограничена 8 заданиями (фрагменты, главы, полные книги или пробы голоса), синтез выполняется последовательно. Лимит текста — 3 млн символов. Старые файлы удаляются перед новой генерацией, когда кэш заполнен; файлы, использованные за последние 24 часа, сохраняются для текущего прослушивания. При нехватке места подготовка завершится ошибкой. Ссылки на аудио подписаны и действуют 24 часа; после перезапуска сервера получите новую ссылку кнопкой подготовки. Ссылка предоставляет доступ к записи, поэтому её следует хранить как приватную.

При ошибке проверьте `docker compose -f docker-compose.yml -f docker-compose.silero.yml logs silero`. Для тестов: `npm run test:tts`; проверка настоящего сервиса: `node scripts/reader-speech-tests.js --silero-url http://127.0.0.1:8000`.

Модель скачивается отдельно и не включается в дистрибутив INPX Web. Русские веса опубликованы под лицензией с ограничением коммерческого использования; условия приведены в [официальном Silero Models](https://github.com/snakers4/silero-models#licence).
