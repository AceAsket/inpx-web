# Озвучка книг через Silero

Экспериментальная серверная озвучка русских FB2, **выключенная по умолчанию**. Включается только при запуске контейнера переменной `INPX_TTS_ENABLED=true`; настройки администратора эту опцию не меняют. Silero работает в отдельном CPU-контейнере; основное приложение не требует Python или PyTorch. Текст книги передаётся только вашему сервису Silero.

## Docker Compose

Используйте текущие пути библиотеки и данных в `docker-compose.yml`, затем:

```sh
export INPX_TTS_ENABLED=true
docker compose -f docker-compose.yml -f docker-compose.silero.yml --profile tts pull
docker compose -f docker-compose.yml -f docker-compose.silero.yml --profile tts up -d --no-build
```

Для стенда RC4 опубликованы образы `aceasket/inpx-web-7z:1.7.9-rc.4` и `aceasket/inpx-web-7z:1.7.9-rc.4-silero` для Linux x64. Возьмите `docker-compose.silero.yml` из тега `v1.7.9-rc.4`; основной Compose-файл с вашими путями и портами сохраняется. Для сборки из исходников замените `--no-build` на `--build` и пропустите `pull`.

При первой озвучке сервис скачает официальную модель `v5_5_ru` в постоянный том `silero-models`. Для первого запуска нужен доступ к `models.silero.ai`; последующие запуски используют локальную модель. Контейнер по умолчанию использует до 4 CPU и 4 ГБ RAM. `/health` проверяет доступность HTTP-сервиса; модель загружается при первом запросе синтеза.

Сервис Silero включён в необязательный Compose-профиль `tts`. Без `--profile tts` он не запускается; основной контейнер работает без него. Сам адрес `INPX_TTS_URL` не включает озвучку. Чтобы выключить озвучку, задайте `INPX_TTS_ENABLED=false` и пересоздайте основной контейнер; ненужный сервис можно остановить командой `docker compose -f docker-compose.yml -f docker-compose.silero.yml stop silero`.

Для существующего контейнера INPX Web на Unraid загрузите сервис отдельно:

```sh
docker pull aceasket/inpx-web-7z:1.7.9-rc.4-silero
```

Подключите оба контейнера к одной пользовательской Docker-сети, запустите Silero с именем `silero`, портом `8000` внутри сети и постоянным томом `/models`. В **новой сборке** INPX Web задайте `INPX_TTS_ENABLED=true` и `INPX_TTS_URL=http://silero:8000`. При использовании разных хостов укажите адрес и доступный порт вашего Silero. После изменения переменных пересоздайте контейнер INPX Web.

## Использование

Войдите в профиль, откройте FB2 в читалке, нажмите значок наушников, выберите голос и «Подготовить озвучку». Когда появится плеер, нажмите ▶. Доступны пять русских голосов: Xenia, Kseniya, Бая, Айдар, Евгений.

Готовится **вся книга**, поэтому первая подготовка большого романа на CPU может быть длительной. До завершения синтеза прослушивание недоступно. Повторное открытие того же текста с тем же голосом использует кэш. Смена голоса создаёт отдельную запись. Оглавление главы и основной текст читаются; описание, изображения, маркеры сносок и тело `notes` пропускаются.

Плеер использует один MP3-файл, HTTP Range для перемотки и Media Session для кнопок на экране блокировки. После старта ему не нужна работа JavaScript для переключения фрагментов. Это рассчитано на воспроизведение с выключенным экраном, но поведение необходимо проверить на вашем телефоне и браузере. Для подготовки держите страницу открытой; сервер продолжит работу и после её закрытия, а повторная подготовка найдёт существующее задание или файл.

Место и скорость сохраняются в этом браузере отдельно для профиля, книги и голоса. Синхронизация позиции аудио между устройствами и привязка к текущему абзацу читалки пока отсутствуют. Закрытие плеера, смена книги, выход или смена профиля останавливают звук; сворачивание плеера сохраняет воспроизведение.

## Настройка

Разделители вроде `***` пропускаются, целые числа преобразуются в русские слова. Самостоятельные абзацы без русских букв и чисел пропускаются: эта модель предназначена для русского текста. Грамматическая обработка дат, дробей и порядковых числительных пока отсутствует.

| Переменная INPX Web | По умолчанию | Назначение |
| --- | --- | --- |
| `INPX_TTS_ENABLED` | `false` | Явно включает озвучку только при значении `true`; одного адреса недостаточно |
| `INPX_TTS_URL` | пусто | Адрес Silero; без него кнопка озвучки скрыта |
| `INPX_TTS_MODEL` | `v5_5_ru` | Должна совпадать с `SILERO_MODEL` сервиса |
| `INPX_TTS_CACHE_SIZE_MB` | `4096` | Лимит кэша MP3, минимум 64 МБ |
| `INPX_TTS_TIMEOUT_MS` | `3600000` | Максимальное ожидание синтеза одной книги, в миллисекундах |
| `INPX_TTS_API_KEY` | пусто | При необходимости Bearer-ключ, совпадающий с `SILERO_API_KEY` сервиса |

Переменные сервиса: `SILERO_MODEL=v5_5_ru`, `SILERO_MODEL_DIR=/models`, `SILERO_THREADS=4`, необязательный `SILERO_API_KEY`. Не публикуйте незащищённый сервис в интернет; пример Compose оставляет его доступным только внутри сети.

MP3 хранятся в `<dataDir>/speech`. Очередь ограничена 8 книгами, синтез выполняется последовательно. Лимит текста — 3 млн символов. Старые файлы удаляются перед новой генерацией, когда кэш заполнен; файлы, использованные за последние 24 часа, сохраняются для текущего прослушивания. При нехватке места подготовка завершится ошибкой. Ссылки на аудио подписаны и действуют 24 часа; после перезапуска сервера получите новую ссылку кнопкой подготовки. Ссылка предоставляет доступ к записи, поэтому её следует хранить как приватную.

При ошибке проверьте `docker compose -f docker-compose.yml -f docker-compose.silero.yml logs silero`. Для тестов: `npm run test:tts`; проверка настоящего сервиса: `node scripts/reader-speech-tests.js --silero-url http://127.0.0.1:8000`.

Модель скачивается отдельно и не включается в дистрибутив INPX Web. Русские веса опубликованы под лицензией с ограничением коммерческого использования; условия приведены в [официальном Silero Models](https://github.com/snakers4/silero-models#licence).
