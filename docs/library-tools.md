# Задачи, избранное и проверка библиотеки

Изменения в `develop` после 1.8.1-rc.10; в опубликованном RC10 этих функций ещё нет.

## Задачи

После входа в профиль над каталогом доступна кнопка «Задачи». Видны индекс числа
голосов и подготовка аудио своего профиля. Администратор также видит конвертации,
проверку библиотеки и общую загрузку очереди. Чужие задания озвучки обычному профилю
не показываются. Ссылки на аудио и ключи доступа в ответ со списком задач не входят.

Показываются этап, очередь, обработанное количество и предварительное оставшееся
время, если для него есть данные. Для операций без измеримого объёма используется
неопределённый индикатор. Конвертеры не сообщают точный процент, поэтому интерфейс
показывает этап и ожидание общих ресурсов. Общие лимиты по-прежнему задаются
переменными `INPX_RESOURCE_*` при запуске контейнера.

Поиск по числу голосов сначала проверяет готовность индекса короткими запросами.
Пока индекс строится, показывается сообщение с количеством обработанных книг;
поиск продолжается автоматически после готовности. Повторные поиски используют
один процесс ожидания и один индекс. Ошибка построения возвращается пользователю,
повторный поиск позволяет попробовать ещё раз.

История задач хранится в памяти текущего процесса и ограничена по числу завершённых
записей и времени хранения. Перезапуск её очищает; готовый кэш книг и аудио сохраняется.

## Избранные авторы и серии

Кнопка «Избранные авторы и серии» доступна после входа в профиль. Укажите полное имя
автора в форме каталога или полное название серии. Начальные значения подставляются
из текущего поиска. При добавлении запоминаются уже имеющиеся книги; они не становятся
новыми уведомлениями. Проверка при открытии окна и кнопка «Проверить новые книги»
сравнивают текущий состав с предыдущим снимком по UID, поэтому дата из INPX не влияет
на обнаружение добавленных книг.

В ленте отображаются новые книги после обновления коллекции. Кнопка «Просмотрено»
очищает уведомления выбранной подписки, не меняя отметки прочитанности самих книг.
«Не следить» удаляет подписку этого профиля. Лента не отправляет сообщения в Telegram
или email. Ссылки автора, серии и книги открывают соответствующий поиск в каталоге.

Лимиты: до 20 подписок в профиле, до 5000 книг в одной подписке. Слишком широкий
запрос отклоняется. Лента показывает до 200 уникальных книг за раз с предупреждением
и ссылками на полные подборки; остальные уведомления остаются в профиле. Подписки,
снимки и непросмотренные UID входят в экспорт и импорт профиля. Старый экспорт без
подписок не очищает существующее избранное. Запоздавшая проверка не восстанавливает
подписку после удаления и не отменяет действие «Просмотрено» с другого устройства.

## Проверка библиотеки

Администратор запускает проверку вручную из окна «Задачи». Одновременно выполняется
одна проверка. Её можно отменить; закрытие окна только прекращает опрос статуса.
При обновлении поискового индекса проверка останавливается с предложением запустить
её заново, чтобы не смешивать разные состояния коллекции.

Быстрый режим проверяет наличие архивов, файлов и записей внутри архивов. Глубокий
дополнительно читает FB2/EPUB: проверяет XML и корневой элемент FB2, контейнер EPUB и
его OPF. Это проверка структуры, без проверки полного соответствия XML-схеме или
доступности каждого внешнего изображения FLibrary. Для других форматов содержимое
помечается пропущенным. Удалённые записи INPX пропускаются.

Исходники не изменяются. Разрешены только пути внутри выбранного источника;
ссылки за его пределы попадают в отчёт. Книги читаются ограниченными пачками,
одновременно открыто не более четырёх архивов. Системные команды и чтение содержимого
используют общий бюджет ресурсов с фоновым приоритетом. Нельзя запустить проверку
файлов поставщика через подключённую удалённую библиотеку — она запускается на
самом поставщике.

По умолчанию содержимое одной книги ограничено 64 МБ; превышение считается пропуском,
а не повреждением. Значение задаётся только при запуске:

```sh
-e INPX_AUDIT_MAX_BOOK_MB=64
```

Также поддерживается `INPX_AUDIT_MAX_BOOK_BYTES` с приоритетом перед мегабайтами.
Для XML контейнера и OPF действуют дополнительные ограничения размера.
Отчёт содержит счётчики и первые 500 замечаний; его можно скачать в JSON.
Сохраняется только последний отчёт в памяти процесса. Отсутствующий источник
прерывает проверку вместо выдачи всей коллекции за повреждённую.

## Таймер сна и переход между чтением и озвучкой

В плеере доступны 15/30/60 минут и остановка в конце главы. В режиме «Слушать сразу»
внутренний фрагмент не считается концом главы: остановка учитывает границу исходной
главы. Следующая запись может быть подготовлена, но автоматически не воспроизводится
после срабатывания таймера. Проверяется абсолютное время, в том числе при событиях
плеера после пробуждения вкладки; точность остановки в фоне зависит от браузера.
Таймер действует в текущем открытом плеере, закрытие или смена профиля его сбрасывает.

Настройка «После паузы» возвращает на 5 или 10 секунд назад после паузы более 10 секунд.
Перемотка не применяется к пробе голоса и при смене записи.

«Слушать отсюда» находит текущий текст в плане озвучки и начинает соответствующий
фрагмент. В режиме прокрутки берётся видимый абзац; повторяющиеся фразы различаются
по текстовому смещению. Для режима всей книги переключается на «Слушать сразу», чтобы не вычислять
аудиопозицию по приблизительному проценту. «Читать отсюда» ставит звук на паузу,
сворачивает плеер и переносит текст к началу текущего фрагмента. Сохранение позиций
чтения и прослушивания и защита от конфликтов между устройствами продолжают работать.
Точных таймингов слов сервис не возвращает; переход выполняется к началу фрагмента,
а не к произносимому слову. Если исходный текст не найден, выводится сообщение
и предлагается выбрать фрагмент вручную.
