# 1.8.2-rc.19

RC19 включает возможности RC18 и следующие исправления.

- **Поиск в новом оформлении.** В разделах «Авторы» и «Серии» главное поле,
  режим совпадения и подсказки соответствуют выбранному разделу. Одиночный
  запрос переносится в выбранное поле без скрытого фильтра по названию.
  Явное сочетание названия, автора и серии сохраняется. Переключение между
  старым и новым оформлением сохраняет условия и сразу показывает нужные поля.
- **Персональные рекомендации.** В личных настройках профиля их можно
  отключить. Выбор сохраняется на сервере и в резервной копии. При
  отключении подборка исчезает и не рассчитывается; история, полки и
  продолжение серий остаются доступны.
- **ZIP PPMd для коллекций INPX/LightLib.** Записи с методом 98 читаются через
  7-Zip при подготовке превью, чтении и скачивании, загрузке метаданных,
  оценок и проверке содержимого. Обычные записи ZIP сохраняют быстрый путь.
  Сохраняются общий бюджет процессов, ограниченное чтение превью, таймауты,
  отмена и проверка фактического объёма вывода. Частичные результаты не
  публикуются. [Проверка LightLib](lightlib-fork-review.md).
- **Иллюстрации FB2.** WebP/JXL внутри binary, ошибочно помеченные как JPEG,
  нормализуются в PNG с сохранением ссылок. Это исправляет потерю картинок
  и отказ конвертации MOBI. Прежний кэш подготовки обновляется автоматически.
- **Telegram-бот.** Уникальный личный Chat ID из профиля подключает бота
  автоматически; одноразовая ссылка остаётся запасным способом. Смена ID
  отзывает прежний доступ и ожидающие отправки, отключение сохраняется
  после перезапуска. Группы и неоднозначные ID не открывают личный профиль.
  Полки загружаются страницами без раскрытия всех умных подборок; поиск
  использует индекс каталога и допускает короткие названия. Добавлено
  перелистывание новинок, ограничена длина подписи с сохранением emoji.
  [Проверки бота](telegram-bot-review.md).
- **Простой интерфейс `/ebook`.** Основной шрифт увеличен до 30 px, укрупнены
  меню и элементы управления. Для браузеров без поддержки UTF-8 имён
  скачиваемые файлы получают читаемую транслитерацию автора и названия
  с правильным расширением. [Подробности](ebook.md).
- **Рейтинг на обложках.** Компактная плашка использует имеющуюся оценку
  и число голосов; если голосов в данных нет, они не выдумываются.
  Сохраняется настройка показа рейтингов, дополнительные запросы отзывов
  для каждой обложки не выполняются.
- **QR приложения.** Компактный блок над профилем можно скрыть и вернуть
  в настройках оформления. Нажатие предлагает скачивание INPX Reader или
  подключение установленного приложения к серверу. Большой QR доступен
  из настроек даже при скрытом блоке. [Новый интерфейс](shelves-interface.md).

## Обновление

Docker: `aceasket/inpx-web-7z:1.8.2-rc.19`.
Silero: `aceasket/inpx-web-7z:1.8.2-rc.19-silero`.
[Standalone и установщик Windows](https://github.com/AceAsket/inpx-web/releases/tag/v1.8.2-rc.19).

Пересоздайте контейнер с новым тегом, сохранив тома и параметры, и дождитесь
готовности `/ready`. Для ZIP PPMd нужен 7-Zip: полный Docker-образ и
Windows-поставка включают его; для остальных standalone-сборок установите
7-Zip CLI в системе либо задайте путь в настройках конвертеров.
Стабильный `latest` остаётся на 1.8.1. Старые RC не перезаписываются.

## Проверки и ограничения

- 457 локальных smoke-проверок и браузерная проверка поиска на экранах 1440
  и 320 px, включая смену разделов, историю и переключение оформления.
  Переключатель рекомендаций проверен в обоих состояниях с сохранением и
  перезагрузкой страницы; отдельно проверены резервная копия и поздние ответы.
- Три завершённых ZIP PPMd с NAS прошли полную проверку целостности:
  3 203 файла соответствуют записям INPX. Девять реальных книг проверены
  через превью, подготовку к чтению и HTTP-скачивание с повтором из кэша.
- Четыре реальные книги с обложками и иллюстрациями проверены в браузерной
  читалке и через настоящие EPUB/MOBI-конвертеры. В книге с 32 уникальными
  изображениями все картинки декодировались; ссылки EPUB и записи MOBI
  проверены отдельно. Физические устройства в этой проверке не участвовали.
- ZIP PPMd, чтение оценок и общий лимит процессов покрыты отдельными
  регрессионными сценариями. Файлы библиотеки NAS не изменялись.
- На физическом Kindle ещё требуется проверить новый масштаб и имена
  файлов. Длительные замеры CPU/RSS пользовательского контейнера и
  проверка бота с рабочим Telegram API выполняются после установки RC.
  Локальные Telegram-проверки используют тестовый HTTPS API.

Динамические папки LightLib с `edit.zip`/`anno.zip` пока не импортируют
пользовательские исправления; ZIP PPMd подключается обычным INPX-источником.
