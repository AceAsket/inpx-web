# 1.8.2-rc.20

RC20 включает возможности RC19 и следующие изменения.

- **Права в standalone ZIP.** Исполняемый файл `inpx-web` и конвертеры
  `bin/fbc`, `bin/kindling` сохраняют Unix-права `755`. Общий потоковый
  упаковщик используется локально и в Actions. Релизная проверка проверяет
  права в ZIP и после системной распаковки, запускает приложение и настоящую
  EPUB/MOBI-конвертацию из распакованного каталога без `chmod`.
- **Высота блоков чтения.** Широкая карточка «Сейчас читаю» сохраняет ширину
  и выравнивается по высоте с соседним блоком «Недавно читали». Кнопка и
  прогресс находятся у нижнего края. На узких экранах блоки остаются друг
  под другом.
- **Жанр и год.** Под серией текущей книги показаны жанры и год из метаданных.
  История передаёт доступные поля индекса; недостающие сведения берутся
  ограниченным превью только текущей книги. Остальная история не раскрывает
  архивы ради метаданных. Дата чтения или добавления не подставляется вместо
  неизвестного года. Запоздалый ответ прежней книги/профиля не меняет карточку.
- **README.** Выделены поддерживаемые библиотеки ZIP PPMd/7z с WebP/JXL,
  необходимые инструменты, чтение и конвертация, ограничения LightLib.
  Динамические индексы `edit.zip`/`anno.zip` пока не импортируют правки.
- **Telegram.** Проверка токена отделена от состояния приёма сообщений.
  Если токен действителен, но интерактивный бот не подключён, показывается
  предупреждение. Статус обновляется сразу после сохранения и проверки;
  старое уведомление заменяется новым. Исправлена передача ошибки состояния:
  она больше не превращает успешный ответ о статусе в ошибку всего запроса.
- **Уведомления.** Вместо ярких полос используются компактные карточки в
  цветах текущей темы с иконкой результата и кнопкой закрытия. Поддержаны
  узкие экраны, уменьшение анимации и отдельная палитра читалки. Сообщения
  и подписи отображаются обычным текстом без интерпретации HTML.

## Обновление

Docker: `aceasket/inpx-web-7z:1.8.2-rc.20`.
Silero: `aceasket/inpx-web-7z:1.8.2-rc.20-silero`.
[Standalone и установщик Windows](https://github.com/AceAsket/inpx-web/releases/tag/v1.8.2-rc.20).

Пересоздайте контейнер с новым тегом, сохранив тома и параметры. Для
standalone распакуйте весь архив, включая `bin`, в отдельную папку.
Для ZIP PPMd/7z нужен 7-Zip, для WebP — `dwebp`, для JXL — `djxl`.
Полный Docker-образ и Windows-поставка содержат эти инструменты; для других
standalone-поставок установите нужные декодеры отдельно.

Стабильный `latest` остаётся на 1.8.1. Старые RC не перезаписываются.
Для уже скачанного Unix-архива RC19 можно восстановить права из каталога
приложения: `chmod 755 inpx-web bin/fbc bin/kindling`.

## Проверки

- 463 регрессионных smoke-сценария, включая воспроизведение прав `644`,
  проверку содержимого ZIP и запуск файлов после системной распаковки.
- Браузерная проверка жанра, года и ограниченного запроса только текущей
  книги; равная высота и прежняя ширина блоков на больших экранах, отсутствие
  горизонтальной прокрутки на телефонах, светлая и тёмная темы.
- Отдельный браузерный сценарий Telegram: действительный токен при ошибке
  приёма, восстановление, немедленный статус, замена уведомления, темы и
  ширина 320 px. Используются только тестовые ответы без обращений к Telegram.
- Проверки ZIP-поставок включены в CI Linux/Windows и в релизную матрицу
  Linux x64/ARM64, Windows x64 и macOS x64.

Реальные архивы и иллюстрации ZIP PPMd проверены при подготовке
[RC19](rc19-release-notes.md). Проверка физических Kindle/KOReader и
длительные замеры пользовательского стенда остаются аппаратными проверками
после обновления.
