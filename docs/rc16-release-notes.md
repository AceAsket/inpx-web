# 1.8.2-rc.16

RC16 включает все возможности RC15 и его предшественников.

- Обновлено оформление `/ebook`: чёрно-белые страницы, компактная навигация,
  отдельные поля названия и автора для быстрого совместного поиска.
  Интерфейс работает без JavaScript и фонового опроса.
- Добавлены личные обычные и умные полки текущего профиля, в том числе закрытые
  для OPDS. Из полки можно сразу скачать книгу. Список полок не пересчитывает
  запросы, содержимое читается ограниченными порциями.
- Формат скачивания выбирается в `/ebook` и сохраняется в профиле.
  Скачивание учитывает текущий формат даже по старой ссылке; `format=raw`
  не подменяет выбор. Если формат недоступен или преобразование не удалось,
  показывается причина вместо выдачи оригинала в другом формате.
- В веб-превью появились жанры, год издания и ключевые слова. Дата добавления
  подписана отдельно. Метаданные используют прежние ограничения чтения,
  времени, кэша и отмены при смене книги или профиля.
- Локальная OPDS-карточка FB2 откладывает отзывы и полную подготовку книги.
  Ссылки на дополнительные сведения сохранены; удалённые аннотации работают
  по прежнему пути.

Подробности: [электронные книги и OPDS](ebook.md), [превью книги](book-preview.md).

## Обновление

Основной образ: `aceasket/inpx-web-7z:1.8.2-rc.16`.
Silero: `aceasket/inpx-web-7z:1.8.2-rc.16-silero`.
[Standalone-сборки и установщик Windows](https://github.com/AceAsket/inpx-web/releases/tag/v1.8.2-rc.16).
Стабильный `latest` остаётся на 1.8.1; ранее опубликованные RC сохраняются.

Пересоздайте контейнер с новым тегом, сохранив тома и настройки. Дождитесь
готовности `/ready`. Откройте `/ebook` или `/ebook/`; при `server.root=/library`
используйте `/library/ebook`. [Резервная копия и откат](upgrade-rollback.md).
