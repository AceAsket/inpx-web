# 1.8.2-rc.15

RC15 собирает изменения после RC14 и включает его исправления.

- `/ebook` — отдельный простой интерфейс для электронных книг разных моделей:
  серверный HTML без JavaScript и WebSocket, чёрно-белые страницы, обычные
  формы поиска и входа, карточка и скачивание для штатной читалки устройства.
  Фильтры вынесены на отдельный экран, обложки по умолчанию выключены,
  аннотация загружается кнопкой. Есть ограниченное текстовое чтение по страницам.
  Место в этом режиме сохраняется в URL, прогресс полной читалки не меняется.
- OPDS показывает `◔` до 25%, `◑` до 50%, `◕` до 99,9% и `⬤` для прочитанного.
  Используется прогресс выбранного профиля, включая полный вход/OPDS Basic Auth.
  Ссылки сохраняют профиль; персональные ответы не попадают в общий кэш.
  UID и ссылки скачивания прежние, сканирования каталога для отметок нет.
  Скачивание через OPDS само по себе не передаёт позицию сторонней читалки.
- Карточки книг выровнены в ряду; действия расположены внизу, длинные строки
  ограничены в выдаче и доступны полностью в превью.
- Подсказки соответствуют полю названия, автора или серии и появляются от трёх
  символов. В «Обзоре» появились подсказки названий. Переходы сохраняют фильтры,
  поздние ответы не меняют другой запрос или профиль. Исправлен первый выбор языка.
- В превью появилась безопасная текстовая аннотация FB2/EPUB, отдельные ссылки
  авторов и серии. Подготовка метаданных и кэш ограничены; закрытые окна
  игнорируют старые ответы.
- Выбор режима и свои значения производительности сохраняются в браузере
  отдельно по профилям. Один режим и сравнение трёх запускаются явно;
  отчёт показывает проверенные лимиты, критерии, причины рекомендации и
  пояснения CPU/памяти/p95. Настройки работающего сервера тестом не меняются.
- Исправлена OPDS-карточка FB2 без атрибутов корня; проверены разные префиксы xlink.

Подробности: [электронные книги и OPDS](ebook.md),
[аннотация](book-preview.md), [подсказки](catalog-suggestions.md),
[производительность](resource-profiles.md).

## Обновление

Основной образ: `aceasket/inpx-web-7z:1.8.2-rc.15`.
Silero: `aceasket/inpx-web-7z:1.8.2-rc.15-silero`.
[Standalone-сборки и установщик Windows](https://github.com/AceAsket/inpx-web/releases/tag/v1.8.2-rc.15).
Стабильный `latest` остаётся на 1.8.1; RC14 не заменяется новым содержимым.

Пересоздайте контейнер с новым тегом, сохранив прежние тома и настройки.
После запуска дождитесь `/ready`. Интерфейс электронных книг доступен по
`/ebook`, при `server.root=/library` — `/library/ebook`.
[Резервная копия и откат](upgrade-rollback.md).

## Проверки

[Полный CI исходного кода](https://github.com/AceAsket/inpx-web/actions/runs/42403041487):
416 release smoke проверок, TTS, Linux/Windows standalone, Docker lite/full,
реальные конвертеры и девять браузерных сценариев — PASS.
Релизные workflows повторяют проверки из тега перед публикацией.
Браузерные сценарии проверяют поведение, их искусственные метрики не являются
замерами библиотеки пользователя. На конкретных аппаратных электронных книгах
`/ebook` ещё не проверен.
