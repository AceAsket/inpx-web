# Системные голоса в веб-читалке

Кнопка «Озвучка» доступна, если браузер поддерживает Web Speech API. Контейнер Silero
для этого режима не нужен. Текст озвучивается через выбранный голос браузера/ОС;
на сервер INPX для синтеза он не отправляется. Сетевой голос может передавать текст
своему поставщику. В списке указаны язык и тип голоса: локальный или сетевой.

Если Silero включён, его плеер сохраняется: кнопка «Голоса устройства» переключает
на системную озвучку, «Silero · MP3» возвращает к серверному плееру. Два режима
одновременно не играют. Без Silero сразу открываются голоса устройства.

Доступны проба, скорость 0,5–2×, три уровня тона, предыдущая/следующая фраза,
«Слушать отсюда», сворачивание и таймер сна 15/30/60 минут. Скорость системного
голоса задаётся самому движку: готового аудиофайла здесь нет. При паузе или смене
голоса текущая короткая фраза повторяется с начала. Проба не меняет позицию книги.

Последняя фраза хранится в этом браузере отдельно для книги и профиля. Настройки
голоса общие для устройства. Синхронизации этой позиции между устройствами нет.
Текст извлекается из всей открытой книги, включая ещё не показанные страницы;
аннотация, примечания и ссылки с номерами примечаний не озвучиваются.

При сворачивании вкладки, блокировке экрана, закрытии плеера, смене книги/профиля
или уходе из читалки речь останавливается. После возвращения нажмите «Продолжить».
Это ограничение браузерного режима: для прослушивания с выключенным экраном
используйте [Silero MP3](silero-tts.md) либо нативный TTS в Android-приложении,
когда он доступен. Голоса и качество зависят от браузера и ОС.

Локальный FB2 можно открыть в `/#/reader-lab`: загрузка книги и озвучка обходятся
без API книги. Для работы без связи страница приложения должна быть уже доступна,
а выбранный голос — установлен на устройстве. Сетевые голоса без интернета не работают.

Проверки: модульные сценарии входят в `npm run test:release`. Дополнительный
`node scripts/browser-speech-browser-test.js` использует Playwright и собранный
клиент, проверяет UI с детерминированным движком; он не оценивает реальный звук.
