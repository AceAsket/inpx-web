# Подготовка 1.8.2 rc.13

Работа ведётся в `develop` на базе `866263b`. Цель — исправить девять основных
замечаний ревью и подтверждённые проблемы памяти, CPU и кэшей, сохранив профили,
прогресс, закладки, пользовательские фоны и совместимость резервных копий.

## План исправлений

| Этап | Изменения | Критерий завершения |
| --- | --- | --- |
| Целостность данных | Изоляция локального прогресса профилей; стабильные UID при изменении INPX с сохранением прежних ссылок | Вход второго профиля не переносит состояние; обновление метаданных и полная переиндексация сохраняют UID, прогресс и закладки |
| Профили и память | Фоны отдельными файлами; компактные ссылки в общем JSON и browser storage; переносимый экспорт и безопасная миграция | Позиция не читает/копирует изображения; перезапуск, экспорт/импорт и откат сохраняют фоны |
| Поиск | Индексные кандидаты точных и обычных фильтров; неизменный регистр regex; keywords групповой выдачи | Селективный поиск не читает всю библиотеку; Web/OPDS/полки согласованы |
| CPU и загрузка | Переиспользование кэша FB2 при server.root; кэш плана TTS; удаление eager Search | Повторный запрос не парсит книгу; online-фрагменты используют готовый план; Search отсутствует в initial chunk |
| Серверные кэши | Бюджеты и TTL метаданных, рейтингов и витрин; лимиты дискового query cache; лимиты EPUB/7z; очистка batch ZIP | Бюджеты действуют при записи, просроченные данные освобождаются, извлечение ограничено фактическими байтами |
| Браузерные кэши | IndexedDB eviction при записи, устойчивость к quota errors; SW только для статических ресурсов; компактная persistence | Кэш не ломает успешный API-ответ и не сохраняет private/audio ответы |
| Релиз | Версия rc.13, changelog, документация обновления, полный набор проверок и ресурсные замеры | Тесты и production-сборка прошли; ограничения платформенных проверок явно записаны |

## Проверки

- Регрессионные тесты каждого воспроизведённого дефекта, подключённые к release suite.
- Проверки старого формата данных, полной переиндексации, backup/restore, прав доступа и конфликтов прогресса.
- Полный `test:release`, `test:tts` и production-сборка клиента.
- Повторные замеры памяти и CPU на одинаковых синтетических данных до и после.
- Браузерные проверки классического каталога, витрин, переключения профилей, фона и чтения, если доступен браузерный runtime.

Публикация Git-тега, GitHub Release и Docker-образов выполняется отдельным шагом.

Локальные этапы завершены. [Результаты проверок и замеров](./rc13-validation.md).
Полные платформенные сборки проходят через GitHub Actions; для предварительной
сборки всех бинарников используется `workflow_dispatch` с `publish=false`.
