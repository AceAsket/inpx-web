# Security policy

Security fixes target the latest release listed on the [Releases page](https://github.com/AceAsket/inpx-web/releases) and the `develop` branch. When reporting, include the exact build or container tag and platform.

To report a vulnerability, choose **Report a vulnerability** under [Security advisories](https://github.com/AceAsket/inpx-web/security/advisories). Include the affected component, the impact, and enough context to verify the issue. Remove credentials and personal or library data from attachments. Please coordinate disclosure through the private report before sharing details publicly.

# Политика безопасности

Исправления безопасности предназначены для последнего [релиза](https://github.com/AceAsket/inpx-web/releases) и ветки `develop`. В отчёте укажите точную версию или тег контейнера и платформу.

Чтобы сообщить об уязвимости, выберите **Report a vulnerability** в разделе [Security advisories](https://github.com/AceAsket/inpx-web/security/advisories). Опишите затронутый компонент, влияние и условия проверки. Удалите из вложений токены, пароли и личные данные. Согласуйте публикацию деталей через приватный отчёт.
